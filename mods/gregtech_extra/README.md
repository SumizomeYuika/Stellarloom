# 格雷科技·星海扩展（gregtech_extra）

「格雷科技」主题**扩展包**：在 `gregtech_heavy` 之上加
**新矿脉、聚变供电、多方块结构**三条大型玩法线。与原版、重工 mod 兼容。

> **依赖（M6.29 dependencies 声明）**：`gregtech_heavy >= 1.0`。加载器按依赖
> 拓扑序保证**重工先加载、扩展后加载**；缺重工时本 mod 以「缺少依赖」干净
> 失败（模组管理页可见原因），不会带病运行。

---

## 一、新矿脉（世界生成）

开局地面上多出 5 种矿脉（原版只有铁/铜/石）：

| 矿脉 | 挖出 | 冶炼产物 | 稀有度 |
|---|---|---|---|
| 锡矿 | 锡矿石 | 锡锭 | 常见 |
| 煤矿 | 煤 | 直接可用（煤→焦炭/石墨） | 常见 |
| 石英矿 | 石英 | 玻璃 / 碳化硅 | 中等 |
| 锰矿 | 锰矿石 | 锰锭 | 稀有 |
| 钨矿 | 钨矿石 | 钨锭 | 极稀有 |

- 矿脉照常被**采矿机**自动采（改的是渲染、挖掘掉落，不碰原版矿）
- 新开的图、以及旧档断档重建的世界都会补种（WorldGrid 钩子）
- 新矿冶炼有科技门槛：锡/煤/石英要「采掘学 I」，锰/钨要「合金学 I」

## 二、新机器（4 台）

| 机器 | 位置 | 作用 | 耗电 |
|---|---|---|---|
| **金属成型机** | 星际工业 | 锭 → 板材（成型更快） | 1.0 |
| **化工厂** | 星际工业 | 合金化与化工（青铜/玻璃/石墨/碳化硅/合金钢） | 1.5 |
| **聚变反应堆** | 星际工业 | 烧氘芯发电（见下） | 0.5 |
| **粒子加速器** | 星际工业 | 等离子体对撞 → 反物质 / 反物质引擎 | 2.0 |

### 聚变供电（机制亮点）

反应堆加载「氘芯」燃料：填上燃料后，只要**能正常开工**（有燃料、产物格有
空位）就按台数向电网注入电力，单台 **60 电力/秒**（对比：出生核心 8，
可在配置里改）。燃料烧完立刻掉电——所以想稳定供电得喂足氘芯、及时清走
氦-3/等离子体。

> 氘芯 = 钨钢板×2 + 玻璃×4（化工厂，8s）→ 反应堆烧 20s → 氦-3×2 + 等离子体×2。
> 等离子体正是粒子加速器造反物质的原料——闭环！

## 三、多方块结构（2 座）

以 1×1 建筑拼出 3×3 结构：**核心 + 8 块环砖**。环不完整时核心**无法加工**
（进度冻结，不吞材料），拆掉任何一块砖就停工；环补全自动恢复。

| 结构 | 环砖 | 核心 | 配方方向 |
|---|---|---|---|
| **大型高炉** | 耐热砖块 | 大型高炉核心 | 批量冶炼（6 件/次）、大批玻璃/SiC |
| **重型装配平台** | 合金框架 | 重型装配平台核心 | 终局：曲率驱动器 |

## 四、科技线（8 项，接续在重工科技树后）

`采掘学 I → 金属成型 I / 化工厂 I → 合金学 I → 大型结构 I`
`→ 聚变供电 I → 粒子加速 I → 重型装配 II`

- 前三级吃**电磁矩阵（蓝）**，高段初始吃**能量矩阵（红）**
- 加载时自动完成联动升级（依赖声明保证重工已在场）：`合金学/大型结构/
  聚变供电` 改吃**结构矩阵（绿）**，`粒子加速/重型装配` 改吃
  **量子矩阵（青）**——完整的四级科研包体系

依赖声明保证了加载顺序，所以**不再需要等首个游戏帧**——`on_load` 里就升级：

## 七、设计说明（诚实边界）

- `Machine` 类有 `__slots__`，多方块成型状态用 {id(机器): bool} 登记在
  mod 模块里，每帧 O(1) 校验；机器对象在 sync 时**不会被重建**（组合式
  sync，见下）
- 两个 mod 的机器网络 sync 做成**组合式 replace**：最内层跑“安全原版
  补录”（只动熔炉/制造台），各层只补/清自己的类型——任意加载顺序都不会
  互相清场或丢状态
- mod 一次性操作全部登记还原，卸载后配置表、底栏、mixin 全部复原，
  可反复 加载/卸载；物品用**固定数字注册**（M7 注册表旧式兼容路径），
  存档以 `gregtech_extra:item<id>` 名字持久化、数字可反查，跨版本零漂移
- 反应堆注电走 `on_step` 每帧结算，比电网结算晚一帧——无感知
- 卸载本 mod 后，旧档里它的物品显示 "?"（存档数据永远在，预期行为）

## 玩法提示

1. 开局先把铁线铺顺，研究「采掘学 I」开锡/煤
2. 化工厂出青铜锭 → 金属成型机出青铜板（高阶建材）
3. 「大型结构 I」后：核心+8 砖 = 大型高炉，批量冶炼
4. 「聚变供电 I」：钨钢→氘芯→反应堆，从此电网自由
5. 「粒子加速 I」：等离子体→反物质→反物质引擎
6. 终局「重型装配 II」：合金框架环 + 反物质引擎 + 碳化硅 → **曲率驱动器**，
   跨星海吧
