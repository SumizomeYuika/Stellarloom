# 格雷科技：星织重工（GregTech: StellarLoom Heavy Industry）

仿照 Minecraft 著名整合包核心模组 **格雷科技（GregTech）** 的精神，为《星织：无尽沙盒》
写的一个**大型科技重工业 mod**：把「格雷式」的昂贵、多步、带副产物的材料学，塞进
StellarLoom 的自动化体系里。

> 需要游戏版本 M6.27+（mod 系统）。把整个 `gregtech_heavy/` 目录放进项目根 `mods/`
> 后重启游戏即可。卸载 = 删除目录（或由加载器还原），不留任何源码改动。

---

## 一句话玩法

```
原矿 ─粉碎机→ 粉碎矿石 ─离心机→ 洗净矿石 + 硫粉/稀土粉
洗净矿石 ─高炉→ 铁锭/铜锭 ─高炉(焦炭)→ 钢锭 + 高炉渣
铁锭/铜锭/钢锭 ─熔炉/高炉→ 铁板/铜板/钢板
马达 ← 磁铁+铜线+铁锭    活塞 ← 马达+铁锭+齿轮    线圈 ← 铜线+钢锭
高级电路板 ← 电路板+铜线   处理器 ← 高级电路板+硅晶圆   处理器单元 ← 处理器×2
超导线圈 ← 石墨烯+磁线圈+处理器    激光组件 ← 处理器单元+钢板+石墨烯
聚变线圈 ← 超导线圈×2+激光组件×2    星织引擎 ← 聚变线圈（终极里程碑）
```

科研包从 2 级变 4 级：**电磁矩阵（蓝）→ 能量矩阵（红）→ 结构矩阵（绿）→ 量子矩阵（青）**。
三级以后的科技全部吃新科研包，逐级把上面的配方链解锁。

## 新内容一览

### 四台新机器（建筑类型 20–23，底栏新增「重工」分类）

| 建筑 | 干什么 | 解锁科技 |
|---|---|---|
| 粉碎机 | 原矿 → 粉碎矿石 | 矿石学 I |
| 高炉 | 焦炭 / 铁锭 / 铜锭 / 钢锭（+炉渣）/ 硅锭 | 高炉冶金 I |
| 离心机 | 洗净矿石 + 硫粉 / 稀土粉；硅晶圆；石墨烯 | 矿物离心 I / 微电子 I / 材料化工 I |
| 组装线 | 处理器单元 / 超导线圈 / 激光组件 / 聚变线圈 / 星织引擎 | 重工产线 I 起 |

新机器拥有：专属渲染图案、独立配方表、科技解锁、电网耗电、底栏按钮、放置自动开面板、
拆除全额退料（含机内储存）——与原生机器体验一致。

### 32 种新物品（ID 1000–1040 段）

矿物加工中间品（粉碎/洗净/锭/板）、副产物（硫粉/稀土粉/炉渣）、焦炭、硅晶圆、
石墨烯、七种元件（马达/活塞/线圈/高级电路板/处理器/处理器单元/超导线圈/激光组件——
数了下是八种）、两台终极件（聚变线圈/星织引擎）、四台机器、两级科研包。

### 11 项新科技（三级/四级科研包驱动）

```
矿石学 I ─┬─ 高炉冶金 I ─┬─ 电机工学 I ─┬─ 微电子 I ─┬─ 重工产线 I ─┬─ 量子电子 I ─┬─ 聚变技术 I
          └─ 矿物离心 I ─┴─ 材料化工 I ─┘            └─ 传动学 IV     └─ 量子电子    └─ …
```
外加两个全局增益科技：

- **传动学 IV**：传送带速度再 +25%（叠在 speed1~3 之上）
- **生产加速 I**：全部机器生产速度 +25%

### 副产物系统（格雷科技招牌）

- 离心粉碎铁矿石 → 洗净铁矿石 **+ 硫粉**
- 离心粉碎铜矿石 → 洗净铜矿石 **+ 稀土粉**
- 高炉炼钢（铁锭+焦炭）→ 钢锭 **+ 高炉渣**
- 硫粉 + 稀土粉 + 硅石 → **石墨烯**（四级材料，做超导线圈/激光必须）

副产物是高级配方的硬性原料——不把 GT 处理链走通，就永远造不出高级元件。

## 设计取舍与说明

- **不给新矿脉**：原生世界只有铁/铜/石三种矿。处理链直接吃这三种原生矿，
  把「开采 → 多步加工」的深度做在机器里，完全兼容原生地图与存档。
- **新机器 = 新建筑类型**：通过 mixin 让 MachineNetwork / 放置 / 拆除 / 面板 /
  底栏 / chunk 渲染全部认识它们；卸载时全部还原，游戏源码零改动。
- **配方全部可自动化**：与原生设计一致（`machines` 均非空），手搓只是慢速通道。
- **科研包垄断**：结构矩阵/量子矩阵只能由科研站制造（与电磁/能量矩阵同规则）。
- **存档**：mod 物品以数字 id 存盘（M7 起存档/配方 JSON 以
  `gregtech_heavy:item<id>` 名字持久化，运行期经注册表换算回同一 id），
  数字可反查、名字可解析，跨版本零漂移；读档时 mod 必须在场（换回 mod 即可）。
- **平衡**：偏格雷式「贵」：高炉 3 电/秒、钢锭链要两座高炉一进一出、
  星织引擎要 12 秒 + 一整串上游。请规划好流水线。
- **多 mod 兼容**：机器网络 sync 是「组合式 replace」——不调用原版破坏性
  sync（避免机器对象被清空重建导致面板引用失效），每层只补/清自己管辖的
  类型，别的 mod 的机器一律不动。与 `gregtech_extra` 联装（v1.2 起由
  扩展的 dependencies 声明保证加载顺序，谁先装都行）；卸载逐层还原。
- **新开局会换 sim**：mod 的每帧钩子动态取当前世界对象，不持有旧引用。

## 配置（M6.29）

作者默认 `config.json`，玩家可在 `mods/config/gregtech_heavy.json` 覆盖
（改配置无需动 mod 包，重启保持）：

| 键 | 默认 | 含义 |
|---|---|---|
| `production_accel` | `1.25` | 研究「生产加速 I」后全部机器的生产速度倍率 |
| `toasts` | `true` | 加载/卸载时的游戏内提示 |

## 玩法建议（格雷玩家习惯）

1. 先走原版：蓝鼠研到「电子学 I」→ 研究「矿石学 I」解锁粉碎机。
2. 铺一条「矿 → 粉碎机 → 离心机 → 高炉」的迷你产线，把副产物囤起来。
3. 高炉出钢锭 → 熔炉轧钢板 → 制造台做马达/处理器 → 研究三级科技。
4. 攒结构矩阵（绿）→ 组装线时代 → 量子矩阵（青）→ 聚变线圈 → 星织引擎。
