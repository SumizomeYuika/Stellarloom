# Jade（WAILA 风格悬停信息弹板）

仿 Minecraft **Jade**（原 WAILA）做的悬停信息显示 mod：

把鼠标/手指指向某个建筑或矿脉时，屏幕**顶部中央**会弹出一个半透明信息板，
实时显示这个格子的状态——不用点开任何面板。

```
┌────────────────────────────────────────────────┐
│  ◼ 太阳能                                      │
│  发电 37.50 kW                                 │
│  白天                                        │
│  电网 1/2 张 · 9 节点                           │
│  网内 发电 212.5 kW / 需求 134 kW               │
│  电力充足 ██████████ 100%                      │
│  来源 原版                                     │
└────────────────────────────────────────────────┘
```

## 电网联动（M9 真电网）

- 悬停**发电建筑**（太阳能 / 风力 / 核心）或**电力塔**时，多显示所属电网状态：
  电网编号（多网时 n/总）、节点数、网内发电/需求、电力充足率进度条。
- **电网覆盖层**：鼠标所在的整张电网所有节点格用半透明颜色铺一层，
  **颜色 = 电力充足率（负荷）**：
  - 绿 = 充足（≥75%）· 黄 = 偏紧（≥50%）· 橙 = 吃紧（≥25%）· 红 = 缺电（<25%）
- 一局里可能有多张电网（电力建筑相距 > `POWER_LINK_RANGE` 即断开），
  只染色**鼠标所在的这一张**，其它电网保持原样。
- 悬停整张电网里的任意电力节点（发电/耗电/电力塔/分拣器）都会触发覆盖层；
  覆盖层是纯渲染，不修改任何 sim 状态，坏掉也不会影响弹板。

## 显示内容（按建筑类型）

| 指向 | 显示 |
|---|---|
| 传送带 | 朝向、本格在途物品（带色点） |
| 分拣器 | 朝向、过滤物品、叠在什么建筑上 |
| 采矿机 | 脚下矿种（无限矿脉）、暂存格内容 |
| 熔炉 / 制造台（含 mod 机器） | 配方、进度条、原料槽、产物槽、停工原因 |
| 箱子 | 库存明细（带色点）、总件数 |
| 太阳能 / 风力 / 核心 | 当前发电功率（太阳能区分昼夜与行星相位）+ **所属电网**状态 |
| 电力塔 | 中继节点说明 + **所属电网**状态 |
| 电网节点（任意） | 鼠标在其上时整张电网半透明染色（颜色 = 充足率） |
| 供应塔 / 请求塔 | 过滤、库存、缺货清单、无人机数（3×3 塔身任意格都可看） |
| 科研站 | 研究/制造模式、当前科技进度、囤包情况、制造配方 |
| 太阳帆发射器 | 储帆数、累计发射、戴森云总帆数与发电 |
| 矿脉（空地） | 矿种、右键开采提示 |
| 空气（空白无矿） | 不显示（跟 Jade 一样） |
| **全部** | 底部 **来源 mod**（`原版` / `gregtech_heavy` / `gregtech_extra`…，取自 M7 注册表命名空间，任何 mod 的内容都自动标注） |

## 安装 / 卸载

- 放 `mods/jade/` 目录即可，启动时自动加载（模组管理页可禁用/启用）。
- 卸载自动还原：mixin 由加载器还原，游戏源码零改动。

## 配置（可选）

作者默认在 `config.json`，玩家覆盖写 `mods/config/jade.json`（重启保持）：

```json
{
  "enabled": true,          // false = 关闭弹板
  "max_lines": 10,          // 弹板最多显示几行，超出折叠成 "… 还有 N 行"
  "title_size": 20,         // 标题字号
  "font_size": 18,          // 内容字号
  "bg_alpha": 225,          // 弹板背景透明度
  "show_coords": true,      // 底部显示格子坐标
  "show_source": true,      // 底部显示来源 mod（原版 / gregtech_heavy / …）
  "show_net_overlay": true, // 悬停电网节点时整网半透明染色
  "net_overlay_alpha": 80   // 覆盖层透明度（0~255）
}
```

## 实现说明

- 通过 `ctx.mixin("stellarloom.core.game.Game", "_draw_ui", wrap="after")`
  挂到渲染管线：`Game._draw` 中 `_draw_ui` 之后才是各面板/菜单/`flip`，
  所以弹板 z 序是"世界之上、浮窗面板之下"。
- 纯只读查询（网格 / 网络对象 / 配方表），从不修改 sim 状态。
- 绘制异常自动捕获：只提示一次并自禁，不会拖垮游戏主循环。
- 与其它 mod 共存：机器信息统一走 `Machine` 对象，格雷科技等新机器
  同样能显示配方与进度。
