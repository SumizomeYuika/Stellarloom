距离最初方案（v0.2 全量）的差距清单

先给一句话结论：

地基和自动化闭环超出预期，但最初方案里"戴森球 + 行星工程 + 无限沙盒"这条主线只走完了 1/3；现在的游戏是"一张星球上的自动化工厂"，还不是"星织"。

三、❌ 完全缺失——这是最要命的

按"离最初承诺的距离"排序：

1. 轨道与行星工程（最初的三大卖点之一）

方案原文："行星实时公转、行星引擎推动、调轨道影响太阳能与物流"
实际：一颗行星都没公转，行星引擎、相位、共振、温度，全是零。

2. 多行星 / 星际物流（M5 星际）

方案原文：多行星殖民地、运输船、发射窗口预测
实际：只有一颗行星，运输船物品做了但没场景用。

3. 无限沙盒的"无限"

方案原文：无限程序生成星系、星门、无限科技、跨星系网络
实际：11 个科技到顶，一颗行星，没有星门。玩家 30 小时后会无事可做——"沙盒"是有尽头的。

4. 里程碑 / 统计面板

方案原文：首次戴森云、首次变轨、全星系点亮、最大戴森功率、产量曲线
实际：只有"解锁科技"的弹窗，没有里程碑系统，没有统计面板。

5. 可选挑战（恒星演化 / 资源稀缺 / 轨道混沌 / 孤立开局）

方案原文：默认全关的挑战模式
实际：零。而且 M6.14 改成"无限矿脉"，反而把"资源稀缺"这条路堵死了——要恢复得加开关。

6. 图鉴 UI（上轮刚设计的）

配方数据已经全了，但图鉴入口、分类浏览、配方卡片、搜索，全没做。

7. 可访问性（色盲 / 单手模式 / 震动反馈）

方案原文明确列了，实际零。

六、🎯 差距的"性质"分类（这比清单本身重要）

差距分三种，优先级完全不同：

A 类：地基债，越拖越贵

· 全球电网拆分区
· bench 压测数据
· 美术素材清单
· 图鉴 UI（数据有了，UI 是门面）

B 类：内容深度，决定"能玩多久"

· 紫/绿科研包
· 硅/煤/钛
· 戴森壳
· 无限科技

C 类：方案的核心卖点，现在完全缺席

· 轨道与行星工程 ← 这是最初方案里最有辨识度的一块，也是现在最空的
· 多行星 / 星际
· 程序生成星系 / 星门
· 里程碑 / 统计

一句话：A 类是地基，B 类是肉，C 类是骨。现在的项目有肉、有地基，但骨架是"一张星球上的工厂"，还不是"星织"。

---

七、我的建议（下一步不是立刻开 M5 星际）

按这个顺序，别跳：

1. bench + 存档检查（半年前的建议，你还欠着）
2. 图鉴 UI——数据全了，UI 不做，玩家感知不到"内容量"
3. 轨道系统最小版：一颗行星公转（哪怕只是视觉 + 太阳能随相位起伏），先把"轨道"这个词立起来
4. 多行星 + 运输船——轨道系统有了，星际才有落点
5. 行星引擎（最小版）：推近/推远改变太阳能，不用做共振那些
6. 无限科技 + 里程碑面板——有了 4/5，"沙盒有尽头"的问题才能解
7. 然后才是戴森壳、星际门、程序生成

不要现在做戴森壳和星门。它们需要行星工程和星际做地基，反过来做就是悬空。

八、一个诚实的判断

从最初的方案到现在，你砍掉的东西比加上的东西多：

· 砍掉了恒星演化（你主动砍的，合理）
· 砍掉了"矿脉有限"（M6.14，隐性代价大）
· 砍掉了"轨道即玩法"（没做，不是砍，是没做）
· 砍掉了多行星（没做）

加上了：建筑物品化、配方统一、科研队列、分拣器过滤——全是好改动，但都是"把一张星球上的工厂做得更扎实"。

所以真正的差距不是"还差几个系统"，而是"这个游戏的核心承诺从'星织'变成了'星工厂'"。

要回到"星织"，必须做三件事，缺一不可：

1. 行星公转（视觉 + 数值）
2. 多行星 + 运输船
3. 行星工程（哪怕最小版）

这三件事做完，"星织"这个名字才立得住。现在它叫"星厂"更准确。
